Shadows & blurs

8 elevation levels · 4 inner · 5 colored glows · 5 focus rings · 8 blurs · click any to copy CSS

Design principle

Every elevation shadow is a two-layer stack — a sharp close-shadow that grounds the element + a soft ambient shadow that simulates light bleed. Together they produce natural depth that single-shadow systems can't match. Bump up exactly one level on hover.

Elevation · 8 levels
From flat (none) to maximum overlay (3xl) · plus skeu for tactile button feel
Inner shadows · 4 levels
For pressed states, inset wells, scroll indicators, divided panels
Colored glows · for emphasis
Use sparingly on primary CTAs, error states, AI-thinking indicators
Focus rings · 4px @ 24% opacity
Applied on :focus-visible for keyboard navigation
Filter blurs · 8 levels
Applied via filter: blur(…) — blurs the element itself
Backdrop blurs · glass morphism
Applied via backdrop-filter: blur(…) — blurs the layer BEHIND the element. Background shown is intentionally vibrant so the effect is visible.

Spacing & grids

4px base unit · 23-step scale · 11-step radius · 12-column grid · 8 container widths

Design principle

Everything is built on a 4px atomic unit. Most production work uses multiples of 8px for the rhythm. Two principles: (1) consistent spacing creates visual hierarchy without extra ink; (2) the 4px unit gives enough granularity for tight UI (icon paddings, badges) while 8px increments dominate for breathing room (card padding, gaps, sections).
