# Logos

The two marks the repository ships, copied verbatim from `public/`.

- **`pulse-logo.svg`** — the PULSE mark: the word "ai" set in Inter Black at 108px on a 120×120 viewBox, filled `#FF7918` (`brand-500`). It is a single-ink SVG with the ink baked into the file, so it does not inherit `currentColor` and must not be recoloured. Use it at 24px and up; below that the tight `-8` letter-spacing closes up. Needs a light ground — on a dark surface, place it on a `bg-primary` or white chip.
- **`scienaptic-logo.png`** — the Scienaptic corporate mark, 11 KB PNG. Use it for attribution — a product footer, a login screen, a deck's credit line — not as a product icon. PNG only; there is no vector version in the repository, so don't scale it past its natural size.

Neither mark may be redrawn, recoloured, stretched, outlined or set inside a shape. If a placement needs something these two can't do, ask for the artwork rather than approximating it.
